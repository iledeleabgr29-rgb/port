Understanding HTML and CSS

HTML (HyperText Markup Language) defines the structure and content of the web page.

CSS (Cascading Style Sheets) controls the layout, colors, fonts, and visual presentation.

Specifying Languages in HTML

You can specify the language for the entire document using the lang attribute on the <html> tag, or for specific elements using the attribute inline:

English: Hello, welcome to the website!

Spanish: ¡Hola, bienvenido al sitio web!
